==== Fixed

* *Root allowlist names the five AsciiDoc root documents (2026-11-17,
owner-authorised).* `+.machine_readable/root-allow.txt+` listed the template's
`+.md+` names, so the root-shape check rejected `+CHANGELOG.adoc+`,
`+CONTRIBUTING.adoc+`, `+SECURITY.adoc+`, `+FUNDING+` and
`+PROOF-PROGRESS.adoc+`, here and on `+main+`. The five are added; the `+.md+`
entries are left as they were.

* *Workflow lint reads the SPDX header block (2026-11-17).* The lint tested
line 1 of each workflow for the SPDX identifier, but `+gh actions-lock+` puts
its own banner on line 1 whenever it refreshes the lockfile, so the test failed
on 25 of 25 workflows here and on `+main+`. It now reads the leading comment
block, the same test as `+standards+` `+governance-reusable.yml+`. A workflow
with no identifier in that block still fails.

* *Stack coherence: three README references, the checker pin and the scan pin
(2026-11-17).* The README cited a root `+STATUS.adoc+` that does not exist; the
files are `+compiler/STATUS.adoc+` and `+lsp/STATUS.adoc+`, and it now names
them. The trope-check workflow pins trope-checker at `+0dceab6+`, the commit
hermeneia and vocarium move to in the same sweep; between the previous pin
(`+4ecba4f+`) and that commit, trope-checker's `+src/+`, `+schemas/+`,
`+spec/+` and conformance fixtures are unchanged, and the one Idris2 file that
differs differs in comments only. The Hypatia scan pin moves to the revision
that installs OTP 27.3.4.19 (hypatia#1061). Not changed: the O2 obligation in
`+design/elaboration.adoc+` that still names the v0.1
`+Predicated+`-incomparable-to-`+Dropped+` claim. Rewording an obligation is
the owner's.

* *`+docs/status/PROOF-STATUS.adoc+` published a percentage, which PROOF-POLICY
forbids (2026-11-09).* The summary read `+*Overall*: 0% proven+`. §8.4 rule 7 is
explicit — "Never publish 'X% proved', an average grade, or a single confidence
score" — and asks for a count per category with the denominator instead. The
figure was accurate; the form was the forbidden one. It now reads as a census,
with a note recording why. The same line ships in `+rsr-template-repo+`'s
`+PROOF-STATUS.adoc+`, so every repository minted from it carries the same
breach; fixing it there is the solution at source.

==== Added

* *A note saying what `+verification/proofs/+` actually contains (2026-11-09).*
`+docs/status/PROOF-STATUS.adoc+` now records that the directory is the unmodified
mint set, that none of it states a property of HAEC, and that the 0%-proven summary
is therefore the accurate count rather than a backlog against those files. Also
records that nothing there supports a Proof Witness Grade under PROOF-POLICY §8.1,
and that removing the templates (as trope-checker did under ADR 0005 D5) is an
owner decision.
